03 工業通訊

工業通訊總覽

先搞懂「設備之間到底在傳什麼、怎麼傳」，再學各種協定會快很多。

一張圖先建立概念

應用資料｜暫存器、I/O、命令、狀態
工業協定｜Modbus・EtherNet/IP・PROFINET・OPC UA…
傳輸 / 網路｜TCP・UDP・IP
資料鏈結｜Ethernet・MAC
實體｜網路線・光纖・RS-485
工程師的重點：不要把「Ethernet、TCP/IP、Modbus TCP」當成同一件事。它們位於不同層級，彼此組合後才完成一次通訊。

常見協定怎麼選？

需求常見選擇重點
儀表 / 溫控 / 電表Modbus RTU / TCP簡單、普及、容易整合
PLC 與遠端 I/OPROFINET / EtherNet/IP / CC-Link IE循環 I/O 與診斷
高速運動控制EtherCAT高即時性、同步控制
上位系統 / 資料整合OPC UA / MQTT跨系統與資料交換
