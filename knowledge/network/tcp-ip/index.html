03 工業通訊

TCP / IP

TCP/IP 是現代 Ethernet 工控網路的基礎；IP 負責找到設備，TCP/UDP 負責把資料送到正確的應用程式。

核心角色

項目主要工作工程例子
IP設備尋址、跨網段路由192.168.1.10
TCP可靠、具連線、確認與重傳Modbus TCP
UDP低負擔、無連線部分即時或探索通訊
Port識別同一設備上的服務Modbus TCP：502

一次連線可以這樣理解

PLC → 目標 IP → TCP Port → 工業協定 → 資料
例如 PLC 要讀取 192.168.1.20 的 Modbus TCP 儀表：IP 告訴網路「找哪台設備」，Port 502 告訴設備「交給哪個服務」，Modbus 再定義「要讀哪個 Register」。
