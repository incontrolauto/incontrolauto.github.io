03 工業通訊

Modbus RTU / TCP

Modbus 是自動化現場最常見的跨廠牌資料交換協定之一。核心概念是 Client 發出要求，Server 回覆資料。

RTU 與 TCP 的差異

Modbus RTUModbus TCP
常見實體網路RS-485Ethernet
設備識別站號 / Unit IDIP（另有 Unit Identifier）
錯誤檢查CRC由 TCP/IP/Ethernet 機制承擔傳輸完整性；Modbus TCP ADU 不含 RTU CRC
常用 Port—TCP 502
拓樸常見 BusEthernet 星狀 / Switch

常用 Function Code

Code用途
01Read Coils
02Read Discrete Inputs
03Read Holding Registers
04Read Input Registers
05Write Single Coil
06Write Single Register
15Write Multiple Coils
16Write Multiple Registers

最容易踩雷：Register 位址

設備手冊寫「40001」不代表 PLC 軟體一定輸入 40001。有些軟體使用 0-based offset，可能要填 0；不同廠牌定義不同，務必看設備與 PLC 的 addressing 規則。

資料格式也要確認

一個 Holding Register 為 16 bit。遇到 32-bit Integer 或 Float 時，通常會占用兩個 Register，還必須確認 Word Order / Byte Order。

Register N     → High / Low bytes
Register N + 1 → High / Low bytes
→ 組合成 32-bit Integer / IEEE 754 Float
除錯順序：實體配線 → Serial 參數 / IP → Station / Unit ID → Function Code → Register Address → Data Type → Byte/Word Order。
