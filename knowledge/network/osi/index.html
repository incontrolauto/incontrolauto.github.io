OSI 七層

OSI 不是要你死背，而是用來定位：通訊問題到底發生在哪一層。

Layer名稱工控理解例子
7Application設備資料與命令的規則Modbus、OPC UA、MQTT
6Presentation資料格式、編碼、加密TLS / Encoding
5Session連線工作階段管理Session
4Transport端到端傳輸TCP / UDP
3Network跨網段尋址與路由IP / Router
2Data Link區域網路資料傳遞Ethernet / MAC / Switch
1Physical電氣與實體媒介RJ45、雙絞線、光纖

故障排除怎麼用？

  1. L1：網路線有沒有插好？Link 燈有沒有亮？
  2. L2：Switch / VLAN / MAC 層是否正常？
  3. L3：IP、Subnet Mask、Gateway 對不對？能不能 Ping？
  4. L4：TCP Port 是否開啟？連線是否建立？
  5. L7：站號、Register、Function Code、資料格式是否正確？
實務上依照「實體 → IP → Port → Protocol」往上查，通常比一開始就改 PLC 程式有效率。
