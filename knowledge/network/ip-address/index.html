03 工業通訊

IP Address

IP 設定錯誤是現場最常見、也最值得先排除的 Ethernet 通訊問題之一。

IPv4 基本概念

IP AddressSubnet MaskDefault Gateway
設定用途例
IP Address設備在 IP 網路中的位址192.168.1.10
Subnet Mask判斷哪些位址屬於同一子網255.255.255.0
Gateway前往其他網段的出口192.168.1.1

設備設定範例

PLC       192.168.1.10 / 255.255.255.0
HMI       192.168.1.20 / 255.255.255.0
Vision    192.168.1.30 / 255.255.255.0
注意：同一網路中不要配置重複 IP。更換設備時，也要確認舊設備是否仍在線上。

現場快速檢查

  1. 確認 IP 不重複。
  2. 確認雙方 Subnet Mask。
  3. 同網段先 Ping。
  4. 跨網段再檢查 Gateway / Router / VLAN。
  5. Ping 通但協定不通，再往 TCP Port 與應用層檢查。
